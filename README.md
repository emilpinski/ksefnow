# KSeF Now — Tax Automation SaaS

> Automate KSeF (National e-Invoice System) workflows for Polish accounting offices.

**Live:** [ksefnow.pl](https://ksefnow.pl) · **Status:** Live

## What it does
- Invoice ingestion directly from the Ministry of Finance KSeF API
- Automated corrections and compliance checks
- Multi-client dashboard for accounting offices
- Stripe subscription billing with tiered plans

## Tech Stack
`Next.js 15` `TypeScript` `Supabase` `KSeF API (MF)` `Stripe` `Vercel`
